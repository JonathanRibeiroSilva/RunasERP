## 🎓 Trilha de Aprendizado

### Nível 1: Iniciante (1-2 horas)
1. Leia [README Principal](../README.md)
2. Leia [Quick Start](../QUICK-START.md)
3. Execute os testes: `bash tests/test-mvp.sh`

### Nível 2: Intermediário (4-6 horas)
1. Leia [Resumo Executivo MVP](./mvp/RESUMO-EXECUTIVO.md)
2. Leia [Regras de Negócio](./REGRAS-DE-NEGOCIO.md)
3. Explore [Diagramas de Sequência](./DIAGRAMAS-SEQUENCIA.md)
4. Faça [Testes Manuais](./mvp/TESTE-MANUAL.md)

### Nível 3: Avançado (8-12 horas)
1. Estude [Especificação Técnica](./ESPECIFICACAO-TECNICA.md)
2. Analise [Arquitetura de Comunicação](./ARQUITETURA-COMUNICACAO.md)
3. Revise [Guia de Implementação](./GUIA-IMPLEMENTACAO.md)
4. Implemente uma feature seguindo os padrões
